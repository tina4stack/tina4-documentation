### Green Design Principles

- **Zero-dep core** — no unnecessary dependency computation
- **No build step** — Python, PHP, Ruby execute directly; Node.js uses tsx
- **In-memory testing** — SQLite in-memory databases, no disk I/O waste
- **LRU caching** — response cache prevents redundant computation in production
- **ARM64 native** — all frameworks run natively on energy-efficient Apple Silicon

## How to Reproduce

```bash
# Python
cd tina4-python && uv sync && .venv/bin/python -m pytest tests/ -q

# PHP
cd tina4-php && composer install && php vendor/bin/phpunit --configuration phpunit.xml

# Ruby
cd tina4-ruby && bundle install && bundle exec rspec

# Node.js
cd tina4-nodejs && npm install && for f in test/*.ts; do npx tsx "$f"; done
```
