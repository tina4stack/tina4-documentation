# ADR-0047: Graceful shutdown is a six-state machine with a bounded drain plus a guaranteed cleanup reserve

Date: 2026-08-10
Status: Proposed
Supersedes: the state-machine, deadline, validation, programmatic-hook and worker
clauses of ADR-0017, including its "warn and fall back" rule for an invalid
timeout. ADR-0017's intent (drain in-flight work, bounded, exit 0) is retained.
Full contract: `features/009-graceful-shutdown.md`.

## Context

ADR-0017 drained in-flight requests within a bounded timeout. The re-audit
(feature 9) found the Node production-cluster primary dropped an in-flight request
on SIGTERM to PID 1, only PHP had a shutdown hook, Ruby and Node accepted a
zero-second timeout, and a single "whole lifecycle" deadline both starved cleanup
after a slow drain and could not be enforced on uvicorn/Puma, whose native knob
bounds only the drain.

## Decision

- One atomic coordinator per process with states STARTING -> RUNNING -> QUIESCING
  -> DRAINING -> CLEANUP -> STOPPED; SIGTERM/SIGINT owned once.
- `TINA4_SHUTDOWN_TIMEOUT` is the total monotonic budget from QUIESCING, split
  into a bounded DRAIN (`timeout - reserve`, mapped to the production server's
  native graceful timeout) plus a GUARANTEED cleanup reserve of
  `min(5s, timeout/4)`. Cleanup (hooks, resource close, final log flush) cannot be
  starved by a slow drain.
- An invalid, zero or negative timeout fails startup (supersedes warn-and-
  fallback), per Feature 1.
- Removable LIFO application hooks run before framework resource teardown.
- Resources close in reverse-dependency order (reverse-registration as the
  tiebreak), with logging pinned last.
- A worker supervisor: one signal to PID 1 disables respawn, drains every worker
  within the budget and force-kills only stragglers.

## Consequences

- Ruby and Node lose zero-second immediate close; the Node production cluster
  drains and exits 0 instead of dying 143.
- Generated Kubernetes grace stays `ceil(timeout) + 5`.
- The behavior is gated by `shutdown_contract.json`, four runners and a real
  signal/container/broker lab matrix in the build phase.
