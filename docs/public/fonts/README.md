# Fonts

Self-hosted so the page makes no third-party requests. Both are variable fonts
(every weight in one file), Latin subset, from Fontsource 5.3.0:

| File | Font | Source |
|---|---|---|
| inter-latin-wght-normal.woff2 | Inter, upright | @fontsource-variable/inter |
| inter-latin-wght-italic.woff2 | Inter, italic (the slogan) | @fontsource-variable/inter |
| inconsolata-latin-wght-normal.woff2 | Inconsolata | @fontsource-variable/inconsolata |

Both are licensed under the SIL Open Font License 1.1: see Inter-OFL.txt and
Inconsolata-OFL.txt. Inconsolata replaces Consolas (which cannot be embedded on
the web) as the brand's monospace; it was drawn as an open alternative to it.
