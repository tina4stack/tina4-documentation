      A REST route in one file.

      Scaffold with the CLI, add a route, return JSON.

      1. Create
        $tina4 init python my-app
        $tina4 serve
      2. Add a route
        from tina4_python import get @get("/api/hello/{name}") async def hello(request, response): return response.json({"hello": request.params["name"]})
        \Tina4\Get::add("/api/hello/{name}", function(\Tina4\Response $response, $name) { return $response->json(["hello" => $name]); });
        Tina4::Router.get("/api/hello/{name}") do |request, response| response.json({ hello: request.params[:name] }) end
        import { Router } from "tina4-nodejs"; Router.get("/api/hello/{name}", async (req, res) => { return res.json({ hello: req.params.name }); });
      3. Call it
        $curl localhost:7146/api/hello/Ada {"hello":"Ada"}
      • Routing Every HTTP method: GET, POST, PUT, PATCH and DELETE.
      • Path parameters {name} in the path arrives in your handler.
      • JSON responses Return JSON with one call, no serialiser to set up.
      • Swagger docs A Swagger UI at /swagger while you develop, built from your routes.

      The things you'd normally install.

      Shipped, in sync, in all four languages. Nothing to add to a requirements file.

      HTTP

      src/routes/Drop a file in and it's a route. Typed params like {id:int} and {id:uuid} reject bad input with a 404 before your handler runs.
      /swaggerTyped, grouped API docs generated from your routes.
      /graphqlA zero-dependency GraphQL engine, schema built from your ORM models, IDE included.

      Data

      sqlite:///app.dbOne ORM over SQLite, PostgreSQL, MySQL, MSSQL, Firebird and MongoDB.
      tina4 migrateMigrations that apply on boot, once, even when several processes start together.
      FrondOne Twig-compatible template engine: inheritance, macros, filters.

      Realtime

      ws://WebSocket and server-sent events, with a Redis backplane when you scale out.
      background()Queues, file-backed by default. RabbitMQ, Kafka or MongoDB when you outgrow it. No threads.

      Security

      BearerPOST, PUT, PATCH and DELETE need a token by default. GET stays public.
      JWTHS256 and RS256, PBKDF2 password hashing, rate limiting and CSRF form tokens.

      Tooling

      tina4One Rust CLI. init, serve and migrate behave the same in every language.
      /__devRoutes, requests, SQL runner, queue monitor, mailbox, WebSocket inspector, error tracker.
      MCPBuilt-in dev tools, so your assistant drives the real framework.
